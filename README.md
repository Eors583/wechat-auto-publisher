# 公众号改写助手

本地工具：选题/原文 → AI 改写 → 标题优化 → 模板排版 → 写入微信公众号**草稿箱**。

面向运营人员提供**桌面窗口**；开发人员仍可用命令行。

## 运营怎么用（推荐）

1. 双击项目里的 `启动改写助手.bat`  
   或在已激活的虚拟环境中执行：

```powershell
cd D:\Users\PC\Desktop\wechat-auto-publisher
.\.venv\Scripts\activate
python -m app.ui
```

2. 在窗口里：
   - **工作台**：选择内容和目标公众号，然后开始生成文章  
   - **选题库**：多选热点来源、管理关注公众号、收藏或带回文章  
   - **任务中心**：逐篇审核；全部确认后一次写入各公众号草稿箱  
   - **设置 → 模型管理**：添加文章模型、图片模型和自己的 API Key  
   - **设置 → 公众号**：添加公众号凭证并绑定默认创作方案、模板和排版  
   - **设置 → 创作方案**：把文章规则、排版、图片与封面、公众号专属草稿模板和 AI 评审组合成一个方案  
3. 打开微信公众平台，刷新**草稿箱**查看。

首次使用仍需在 `.env` 配好微信凭证，并把电脑出口 IP 加到公众号白名单；大模型
API Key 可由用户直接在“设置 → 模型管理”中添加，无需修改代码或配置文件。Windows 桌面版
使用当前 Windows 用户的 DPAPI 加密保存模型 Key 和公众号 AppSecret，界面和任务记录
只显示掩码。

### 多公众号发布

每个公众号固定绑定一个模型。同一个选题和原文可以同时选择多个目标公众号，程序会：

1. 创建一个批次，并在批次内为每个公众号创建独立异步任务；
2. 并发使用各公众号绑定的模型，分别改写正文和标题；
3. 使用该公众号自己的 AppID / AppSecret 获取访问令牌；
4. 分别生成完整预览；必须逐篇点击“审核通过并加入写入队列”后才可批量写入草稿箱，不会直接群发。

完成后结果按公众号标签页展示，点击公众号名称即可切换查看对应标题、正文预览、
模型、草稿状态和错误信息，不会把所有长文章纵向堆在同一页面。

批量任务保持并发生成，但所有账号都会停在预览确认阶段。默认候选标题不代表审核完成。
审核时看到的模板图片和正文配图会原样进入最终草稿，不再在批量写入时自动清除。

任务中心支持按批次展开公众号文章、查看整体进度、显式审核、批量写入、停止批次、
仅重试失败公众号、复制重新生成和归档。旧任务不会再受“最近 30 条”限制。

### 创作方案

“设置 → 创作方案”可把文章提示词、图片提示词、AI 评审、正文排版以及正文配图和
AI 封面规则组合成一个可复用方案。公众号在“设置 → 公众号 → 管理”中只需选择一次，
日常生成会自动套用，不需要每次重新选择模型、提示词、排版和图片规则。

草稿模板仍严格按公众号隔离：方案只会恢复目标公众号自己的模板绑定和本地快照，
并校验公众号 AppID 与快照完整性；没有该公众号专属绑定、AppID 已变更或快照无法
验证时，会保留该公众号现有模板，绝不会跨公众号复用原始 `media_id`。

### 文章与图片提示词模板

“设置 → 创作方案 → 写作与图片规则”分为文章提示词模板和图片提示词模板两个互相隔离的目录。
文章模板定义受众、观点、语气、结构和标题调性，会在保留系统字数、JSON、加粗等
基础协议的前提下，注入该公众号的正文和标题生成请求；图片模板只进入正文论点配图
与封面主图请求。每个公众号可在“设置 → 公众号”的管理区分别选择两类模板；选择默认模板时
不会使用任何用户自定义模板，默认模板内容也不会出现在自定义模板管理列表中。

### 选题来源与关注公众号

“选题库”按模块拆成热点选题、关注公众号和来源管理。选题来源可独立
启停、单独刷新和多选筛选，当前支持行业 RSS、Bing News RSS、微博/百度热榜、多个
自定义热点 API、手动选题库和关注公众号近期文章。每条选题都会显示真实来源、日期和
最近一次刷新错误。

关注公众号保存名称、微信号、分类、标签、关键词、刷新频率、示例文章链接和抓取方式。
非自有公众号只使用“关注公众号”中配置的、自己管理的公众号后台 Token 和 Cookie，
调用后台编辑器的公众号搜索能力，不再调用搜狗或百度。后台登录态使用 Windows
当前用户加密保存，过期后需重新登录更新；它不是个人微信 Token，也不是 AppID / AppSecret。
该搜索方式不能承诺像目标公众号自己的后台一样完整、实时，运营人员仍可手动补充漏掉
的链接。进入“关注公众号”后，点击某个账号的“查看近期文章”会弹出该公众号自己的
文章列表，并支持按日期、关键词、未读、收藏和未改写状态筛选。弹窗内点击“带去工作台”
会回填本次内容；“直接生成（高级）”会明确使用全部已启用公众号创建并发批次。

### 飞书工具智能体

在“飞书接入”中配置企业自建应用，并选择一个“飞书智能体模型”。该模型只负责
理解对话、给出简短意图判断和执行流程，再从白名单中选择工具；公众号绑定模型仍
负责实际文章改写。

智能体可调用的工具包括：查询公众号、查询和应用公众号创作方案、查询近 7 天多来源热点、收集文章链接、创建多公众号并发改写、查询进度、查看正文、
选择标题/副标题、修改正文、移动或删除段落、按要求二次改写一个段落、查看和恢复
历史版本、查看/重生/删除正文配图、生成或选择封面、重新排版、终止批次以及并发写入
草稿箱。每个飞书会话只操作自己当前绑定的批次；公众号名称会由程序解析为真实 ID，
模型不能自行编造。会修改内容或产生模型费用的操作必须通过一次性确认码确认；写入
草稿箱必须明确发送“确认全部写入草稿箱”，模糊表达不会触发写入。

飞书接入按职责拆分在 `app/feishu/`：`gateway.py` 处理 SDK 和长连接，`events.py`
解析事件，`agent.py` 规划意图，`session.py` 保存会话，`tool_executor.py` 校验并执行
工具，`presenter.py` 格式化结果，`legacy.py` 兼容固定指令，`bot.py` 仅负责串联这些模块。

批次执行期间会监控各公众号任务状态，只在状态变化时主动向飞书推送进度，例如
“抓取原文、AI 改写中、生成标题、套用排版、等待审核、写入草稿箱”。重复状态会
自动去重，运营人员无需反复发送“进度怎么样”。

飞书能力清单位于 `app/feishu/capabilities.py`。所有 `BatchService` 公开操作都必须
声明为“已支持、部分支持或不适用”，已支持项还必须映射到真实工具和处理器。新增
公开批次能力却没有同步声明飞书支持状态时，`tests/test_feishu_capability_alignment.py`
会直接失败。新增运营功能的完成标准统一为：共享业务服务、飞书工具目录、权限与确认
边界、执行处理器、进度/结果反馈及回归测试同时到位；不能只在桌面端复制一套业务判断。

### 模块边界

核心业务通过 `Pipeline` 门面保持统一调用，但内部按职责拆分在 `app/workflows/`：
`generation.py` 只负责抓取、AI 改写与标题，`rendering.py` 只负责模板、排版、正文图片
和封面，`delivery.py` 只负责多图文组合、草稿写入与发布，`context.py` 显式提供数据库、
模型、微信客户端和终止信号等共享依赖。各阶段不反向依赖 `Pipeline`。

批次对外数据结构位于 `app/services/batch_contracts.py`，URL/SSRF 校验位于
`app/services/url_validation.py`；网页运行状态位于 `app/ui/state.py`，模型和飞书配置
面板分别位于 `app/ui/panels/`。飞书消息网关、智能体规划、会话、工具执行和展示仍在
`app/feishu/` 内保持独立。

多公众号生成完成后进入逐篇审核：机器人先主动发送第一个公众号的正文、候选标题
和副标题；回复“标题 2、副标题 1”只会更新当前选择，随后还需回复“确认此文章”。
确认后机器人会自动发送下一个公众号的预览。只有全部公众号都完成标题选择和显式
确认后，才允许执行“确认全部写入草稿箱”。

示例：

```text
查询近7日热点
收藏这个链接 https://mp.weixin.qq.com/s/xxx
用第3条给蓝血经营管理系统和蓝血家族办公室改写
把 https://example.com/article 改写到蓝血经营管理系统和蓝血家族办公室
现在进度怎么样
标题 2、副标题 1
确认此文章
标题 1
确认此文章
确认全部写入草稿箱
```

### 正文智能配图

在“设置 → 模型管理 → 图片模型”添加对应厂商的图片模型，再到“设置 → 公众号”的
“图片与封面”中单独启用和选择。默认规则为每篇 2–4 张、间隔 600–900 字，优先放在
每个完整论点的收束段落之后，不打断论述；没有清晰论点结构时才按案例、关键数据、
方法框架和场景转换选点，并且不会连续插图。程序先匹配该公众号自己的素材库；
没有合适素材时才调用所选图片模型，生成后上传到该公众号，账号之间不会共用素材。

### 同步公众号编辑器模板

公众号后台工具栏里的“模板”没有开放 API。首次使用时，在后台编辑器插入
“蓝血经营管理系统模板”，保留“蓝血经营管理系统正文”占位文字，并保存一篇
临时文章。随后在审核页面点击“同步模板并重新排版”。程序会缓存模板 HTML，
以后自动替换占位正文并通过官方草稿接口写入，无需再次点击后台模板。

## 开发 / 首次安装

```powershell
cd wechat-auto-publisher
python -m venv .venv
.\.venv\Scripts\activate
pip install -e .

copy config.example.yaml config.yaml
copy .env.example .env
# 编辑 .env：WECHAT_APP_ID / WECHAT_APP_SECRET / MOONSHOT_API_KEY 等
```

默认 AI：`manus`。界面支持添加任意 OpenAI Chat Completions 兼容服务（如
DeepSeek、通义、Kimi、智谱和自建网关）以及 Google Gemini。未在界面选择模型时，
仍会使用 `config.yaml` 中的 `ai.primary`，保持命令行和旧配置兼容。

## 命令行（可选）

```powershell
python -m app run --url "https://mp.weixin.qq.com/s/xxx" --mode draft --review
python -m app review --job-id 1
python -m app list-jobs
python -m app desktop
```

## 配置说明

- `.env`：密钥（勿提交 Git）
- `config.yaml`：改写提示词、封面（默认真机素材库随机）、广告尾部等

## 权限前提

公众号已认证；开通草稿箱接口；本机 IP 已加入白名单；素材库有可用封面图。
