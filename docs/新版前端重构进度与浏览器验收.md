## 浏览器尺寸与滚动指标

指标格式均为 `scrollWidth/clientWidth × scrollHeight/clientHeight`。根节点和活动页面数值相等即无页面级横向或纵向滚动。

| 视口 | 根节点 | 活动页面 | 响应式结果 |
|---|---|---|---|
| 1440×900 | 1440/1440 × 900/900 | 1220/1220 × 836/836 | 220px 侧栏、64px 顶栏；完整双栏/三栏结构 |
| 1280×720 | 1280/1280 × 720/720 | 1060/1060 × 662/662 | 220px 侧栏、58px 紧凑顶栏；最近任务隐藏，任务行仍为 68px |
| 1024×768 | 1024/1024 × 768/768 | 948/948 × 710/710 | 76px 紧凑侧栏、58px 顶栏；多栏按断点压缩且无根级滚动 |

1440×900 的任务行实测高度为 `[68, 68, 68, 68]`；审核页 `dialogCount = 0`，正文区和右侧结论区都限制在活动页面高度内。

## 可见交互验证

| 场景 | 本地浏览器结果 |
|---|---|
| 后台生成 | “后台开始生成”在创作台提交栏可见；提交逻辑创建持久化批次，页面不出现阻塞遮罩 |
| 任务进度 | 顶栏后台活动入口、任务行“查看进度”和任务页右栏入口可见；进度使用百分比 |
| AI 后台改写 | 审核页右下后台任务卡保留“按已选意见后台改写”；提交后由后台活动面板持续显示进度 |
| 公众号切换 | 左侧切换账号后，右侧账号名称、授权状态、模型、方案、规则和能力状态按账号重新渲染 |
| 配置保存 | 底部“恢复上个版本 / 保存配置”固定可见；版本列表在右上更多菜单内 |
| 审核确认 | AI 结论区保留“需要修改 / 确认此文章”；事实风险仍由原服务阻断 |
| 审核导航 | 任务行“打开审核”进入全页审核；无 modal；上一篇/下一篇和返回任务队列可见 |

为避免验收制造真实业务数据或外部模型费用，本轮没有真正提交生成、AI 评审、AI 改写、写入草稿或确认文章；浏览器验证覆盖入口、状态、布局和既有持久化调用路径。

## 风险与边界

- 本轮只保留本地服务 `http://127.0.0.1:18765` 供产品验收；未执行 Git push、服务器上传或生产部署。
- 首次进入尚未挂载的业务页仍需创建 NiceGUI 组件；组件创建完成后再切换不重新构建。任务队列已取消固定轮询重绘，后台状态由全局活动面板承担。
- 选题来源在当前本地数据下可能返回 0 条或上游解析失败；新版提供空状态与“刷新所选来源/关注与来源”入口，不以静态示例数据伪装成功。
