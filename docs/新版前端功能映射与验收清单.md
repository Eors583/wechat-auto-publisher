# 新版前端功能映射与验收清单

> 设计基线：`wechat-operations-workbench.html` / `wechat-operations-workbench-browser.html`
> 实施原则：只重排前端信息架构和交互，不改变现有后端契约；设计稿未展示但旧版已具备的能力必须保留可见入口。

## 1. 全局框架

| 原功能 | 新页面入口 | 复用接口 / 实现 | 浏览器验证用例 |
|---|---|---|---|
| 工作台、选题库、任务中心、设置 | 左侧主导航：创作台、选题雷达、任务队列、公众号；文章审核仅由任务行进入 | `create_desktop_app` 按首次访问挂载四个工作区，隐藏 review route 承载全页审核 | 四个一级入口逐一点击；任务行“打开审核”进入同一主壳层，侧栏不增加第五项 |
| 登录用户、角色、退出 | 左侧栏底部用户区 | `current_desktop_user`、`logout_desktop_user` | 显示账号与角色；退出菜单仍吊销会话；本轮不执行真实退出以免破坏测试会话 |
| 配置健康提醒 | 顶部状态入口 / 公众号配置中心 | `OnboardingService.status`、`build_configuration_health_banner` | 异常时可见且能进入对应修复入口 |
| 后台生成、AI 评审和后台改写状态 | 全局右侧后台任务抽屉 + 任务队列 + 审核页内进度 | `BatchService.list_batches`、`list_editorial_reviews` | 离开创建或审核页后仍能看到百分比和详情入口 |
| 视觉规范 | `style_tokens.py` + `styles.py` 公共组件类 | CSS variables / 公共 class | 三种视口检查字体、间距、圆角、阴影和控件高度一致 |

## 2. 创作台

| 原功能 | 新页面入口 | 复用接口 / 实现 | 浏览器验证用例 |
|---|---|---|---|
| 单篇文章链接 | 创作台 → 文章来源 → 文章链接 | `_build_wizard` 的 `link` 模式 | 切换入口后链接输入框可见，其他来源输入隐藏 |
| 粘贴文章正文 | 创作台 → 文章来源 → 粘贴正文 | `_build_wizard` 的 `body` 模式和全屏正文编辑器 | 输入正文、打开全屏编辑、保存回填 |
| 多篇参考资料 | 创作台 → 文章来源 → 多篇参考 | `_build_wizard` 的 `references` 模式 | 每行一个链接输入可见 |
| 纯话题原创 | 创作台 → 文章来源 → 话题原创 | `_build_wizard` 的 `topic` 模式 | 主题为空时仍允许按后端现行规则继续；填写后可提交 |
| 从选题库带回 | 创作台“从选题雷达选择”及选题卡“带去创作” | `AppState.pending_topic`、`_queue_for_wizard` | 点击选题卡后切回创作台并回填内容 |
| 必须保留的事实/资料 | 创作台 → 高级创作设置 | 现有 `must_keep` 输入 | 展开后输入内容仍保留 |
| 轻度/标准/深度改写 | 创作台 → 改写强度 | 现有 `rewrite_strength` 选择 | 三档可选，提交时值进入批次配置 |
| 多选目标公众号 | 创作台 → 目标公众号紧凑账号卡与分页箭头 | `state.account_options`、隐藏多选状态控件、可见账号卡 | 点选/取消账号；显示各账号模型和可生成/可写草稿能力；真实账号超过两项时分页不拉高页面 |
| 生成前检查、仅生成分支 | 点击后台开始生成后的检查结果 | `BatchService.preflight` | 模型不可用阻断；仅草稿权限异常时可选择只生成 |
| 后台生成、停止、百分比、耗时、日志 | 创作台底部任务条 + 全局后台任务抽屉 | 现有后台批次创建和轮询逻辑 | 提交后可切换页面；进度持续；详情可回任务队列；停止按钮可见 |
| 安全模式 | 创作台标题区和全局侧栏状态 | 只写草稿的现有业务边界 | 始终显示“只写草稿，不自动群发” |

## 4. 任务队列

| 原功能 | 新页面入口 | 复用接口 / 实现 | 浏览器验证用例 |
|---|---|---|---|
| 待审核、待确认、正文保留、生成中、失败等状态 | 任务队列分段和紧凑任务行 | `BatchService.review_inbox/list_batches` | 状态文案正确；行高 68px；列表从上向下排列不拉伸 |
| 打开审核 | 待审核任务行主按钮 | `open_review_page` → `build_review_page` | 打开对应文章的全页审核视图，不出现遮罩或模态框，不串公众号或批次 |
| 写入草稿 | 已确认批次/任务主按钮 | `confirm_batch_write` | 二次确认弹窗显示目标公众号和文章数 |
| 恢复失败任务 | 失败任务主按钮与详情中的恢复选项 | `retry_job` / `open_retry_job_dialog` | 从失败步骤、抓取、正文、标题、排版、配图、写入等入口仍可见 |
| 查看进度 | 生成中任务行 / 全局后台任务抽屉 | 批次 progress / job status | 显示百分比、阶段和详情入口 |
| 查看后台运行任务 | 任务队列顶部和全局抽屉 | 活跃批次及评审查询 | 运行任务数量和列表可见 |
| 查看归档 | 任务队列“查看归档” | `include_archived` | 点击后展示已归档批次 |
| 按原设置重生成、停止、归档 | 批次详情 | 现有批次操作 | 操作按钮保留且不被“今日处理顺序”替代 |
| 搜索和筛选 | 任务队列工具栏 | 现有搜索、公众号、状态、今天筛选 | 条件变化后列表更新 |

## 6. 文章审核

| 原功能 | 新页面入口 | 复用接口 / 实现 | 浏览器验证用例 |
|---|---|---|---|
| 待审核文章入口 | 任务队列任务行“打开审核” | review inbox + 隐藏 review route | 点击后进入主壳层内全页审核；文章审核不作为一级导航出现 |
| 成品预览 | 审核工作台中部 | 已渲染 HTML / iframe | 微信最终效果可见，无横向裁切 |
| 标题、摘要、正文编辑 | 审核工作台编辑区 | `save_job_review` / 重排版 | 修改后保存；未保存输入阻止 AI 覆盖 |
| 正文配图、封面 | 审核工作台工具区 | 现有图片生成、素材选择接口 | 整篇/单图重生、删除、封面生成/选择入口可见 |
| 历史版本 | 审核工作台工具区 | job revision service | 列表打开、恢复后回到待确认 |
| AI 评审风险、人工确认 | AI 评审区 | editorial review service | 事实/合规项只能人工核实或接受风险 |
| 需要修改、确认文章 | 底部固定操作栏 | `request_job_changes`、`confirm_job_review` | 状态流转正确；确认后自动进入下一篇 |
| 上一篇 / 下一篇 | 审核页顶部 | 同批次 jobs 定位 | 首尾禁用正确；切换后文章与公众号信息同步 |
| 按已选意见后台改写 | AI 评审区 | `start_editorial_rewrite` | 提交后关闭审核仍继续；全局和页内均显示百分比；完成后必须选择原文或改写稿 |
| 改写前后对比与版本选择 | AI 评审区 | source / rewritten snapshots | 默认不覆盖；明确选择后才更新正文 |

## 7. 响应式与可访问性验收

| 视口 | 验收重点 |
|---|---|
| 1440 × 900 | 左侧导航、三栏创作台/审核区、任务行和右侧后台任务同时可用；页面根节点无滚动条 |
| 1280 × 720 | 顶栏和主内容不裁切；任务行保持 68px；主工作区固定一屏且无可见滚动条 |
| 1024 × 768 | 侧栏收窄；配置双栏、审核多栏按断点重排；无页面级横向/纵向滚动条 |

通用自动检查：`documentElement.scrollWidth === innerWidth`、`documentElement.scrollHeight === innerHeight`、所有主按钮可见、所有彩色圆角图标容器包含语义图标且居中、控制台无新增错误。
