公众号改写助手 · Windows 安装版
版本：1.0.0
版本日期：2026-07-23

本版包含：
1. 多公众号批次并发生成、逐篇显式审核和全部确认后并发写入草稿箱。
2. 每个公众号独立绑定文本模型、图片模型、文章提示词、图片提示词、排版及草稿模板。
3. Kimi、Manus、DeepSeek、通义、智谱及自定义 OpenAI 兼容文本模型。
4. 阿里百炼、MiniMax、火山引擎、智谱及自定义生图接口模板。
5. 按论点数量生成正文配图，在论点结束位置插入；支持 AI 主封面。
6. 审核工作台支持标题/副标题、正文编辑、段落二改、移动/删除段落、单图重生、删图、
   封面重生、版本历史和恢复。
7. 公众号草稿模板保持原图片、视频、跳转组件和名片，仅替换指定正文占位内容。
8. 批次任务中心、失败重试、复制生成、终止、归档、运营数据及完整审核状态。
9. 多来源热点、热点关键词、关注公众号后台文章发现及链接收集。
10. 飞书智能体支持选题、生成、进度、逐篇审核、二次修改和写入草稿工具。
11. 桌面端启动时自动启动本地 API 与飞书长连接服务。
12. 安装后自动执行离线自检，检查模板、数据库、API、飞书工具和生图厂商模块。

安全说明：
- 安装包不包含开发电脑上的 API Key、公众号 AppSecret、飞书密钥或历史数据库。
- 首次安装后请在“设置 → 模型管理”和“设置 → 公众号”中录入自己的凭证。
- 用户配置保存在安装目录 data/app.db，并使用当前 Windows 用户的 DPAPI 加密。
