公众号改写助手 · Windows 安装版
版本：1.3.0
版本日期：2026-07-28

本版包含：
1. 多公众号批次并发生成、逐篇显式审核和全部确认后并发写入草稿箱。
2. 每个公众号独立绑定文本模型、图片模型、文章提示词、图片提示词、排版及草稿模板。
3. Kimi、Manus、DeepSeek、通义、智谱及自定义 OpenAI 兼容文本模型。
4. 阿里百炼、MiniMax、火山引擎、智谱及自定义生图接口模板。
5. 按论点数量生成正文配图，在论点结束位置插入；支持 AI 主封面。
6. 审核工作台支持标题/副标题、正文编辑、段落二改、移动/删除段落、单图重生、删图、
   封面重生、版本历史和恢复。
7. 公众号草稿模板保持原图片、视频、跳转组件和名片，仅替换指定正文占位内容。
8. 批次任务中心、失败重试、复制生成、终止、归档、运营数据及完整审核状态。
9. 多来源热点、热点关键词、关注公众号后台文章发现及链接收集。
10. 飞书智能体支持选题、生成、进度、逐篇审核、二次修改和写入草稿工具。
11. 桌面端启动时自动启动本地 API 与飞书长连接服务。
12. 安装后自动执行离线自检，检查模板、数据库、API、飞书工具和生图厂商模块。
13. AI 评审完成后可逐条选择改进建议并智能修改，审核页会左右对比展示修改前后的标题、
    摘要和完整正文，且不会退出当前审核工作台。
14. 飞书接入页可从已有文本模型中明确选择默认智能体模型，不再静默绑定固定模型。
15. 飞书配置保存后可在页面内直接重启 API 与飞书长连接，无需退出整个桌面应用。
16. 新增严格的 FEISHU_ENABLED 环境开关，并显示当前 enabled 状态及重启后的运行状态。
17. 飞书默认发布公众号改为实时读取：新增、启停、删除公众号后自动同步，并明确提示
    已停用或尚未绑定文章模型的公众号。
18. 新增微信公众号固定 IP 云中转：获取 access_token、上传正文图片和封面、素材/模板
    查询、草稿查询与写入均可通过同一个 HTTPS 网关访问微信官方接口。
19. 云中转支持多位客户使用各自独立的中转账号和公众号 AppID/AppSecret；中转密码使用
    Windows 当前用户 DPAPI 加密保存，页面、日志和状态接口均不回显明文。
20. 云中转启用前会用选定公众号真实获取 token，并只读查询草稿箱；401/403、40164、
    40125、网关超时和证书问题均提供中文处理提示。
21. 微信接口 HTTP 异常已在底层脱敏，错误文本不会携带 AppSecret 或 access_token；
    只读请求允许安全重试，写草稿、上传素材和提交发布不会自动重放。
22. 任务中心新增待处理收件箱，提供待我审核、写入失败、生成失败和今日完成四类入口，
    支持服务端分页、公众号筛选及运营优先级排序。
23. 审核工作台新增快速审核和深度编辑模式；切换、标记需要修改、AI 操作及确认后均
    保持在同一个工作台，并自动继续同批次下一篇未确认文章。
24. 桌面、API、飞书、关注公众号及历史任务统一使用同一批次服务和审核工作台链接，
    工作台不再自行创建任务或直接调用生成 Pipeline。
25. 新增结构化运营错误：明确失败步骤、原因、影响、建议和可执行动作，并在数据库、
    API、桌面、飞书及日志边界统一脱敏。
26. 新增逐阶段原地恢复、跨进程原子抢占、执行次数与模型记录，以及启动会话心跳和
    历史挂起任务自动回收；正文变化会撤销旧审核确认。
27. 固定 IP 中转增加逐公众号五分钟健康缓存、写入前只读预检、最近成功写入时间和
    基础/高级两级配置展示。
28. 草稿写入新增文章版本指纹、持久化防重、并发保护和多页安全对账；响应丢失时先
    匹配标题、封面与规范化正文，无法确认时保持“结果待确认”而不重复创建。

安全说明：
- 安装包不包含开发电脑上的 API Key、公众号 AppSecret、飞书密钥或历史数据库。
- 首次安装后请在“设置 → 模型管理”和“设置 → 公众号”中录入自己的凭证。
- 用户配置保存在中心 PostgreSQL，API Key、AppSecret 和中转密码使用服务器端
  CREDENTIAL_ENCRYPTION_KEY 加密，可在连接同一服务的设备上随账号读取。
