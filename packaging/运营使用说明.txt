公众号改写助手 · Windows 安装版
========================

一、启动
1. 双击“公众号改写助手-安装包-1.3.0-20260728.exe”完成安装。
2. 从开始菜单或桌面快捷方式打开“公众号改写助手”。
3. 如果 Windows 弹出网络访问提示，仅允许专用网络即可。
4. 桌面端会同时启动本机 API（18766）和飞书长连接；关闭桌面端后内置服务会一并停止。

二、使用流程
1. 在“设置 → 模型管理”添加文章模型、图片模型及 API Key。
2. 在“设置 → 公众号”添加 AppID / AppSecret，并绑定模型、创作规则、模板和排版。
   如使用固定 IP 云中转，请先按第五节完成中转配置。
3. 在“工作台”直接填写内容，或进入“选题库”点击“带去工作台”。
4. 在“工作台”核对内容，多选本次要生成文章的公众号，点击“开始生成文章”。
5. 程序会为各公众号创建独立任务，并发生成各自文章。
6. “任务中心”默认打开待处理收件箱；可按“待我审核、写入失败、生成失败、今日完成”
   快速定位工作，逐篇进入同一个审核工作台。
7. 默认使用快速审核，只核对标题、手机预览、评审摘要、封面和阻断问题；需要修改时
   原位切换深度编辑，不关闭页面、不丢输入。
8. 全部确认后，点击“写入已确认的 N 篇”，并发写入对应公众号草稿箱。
9. 到各公众号后台草稿箱刷新查看，程序不会自动群发。

当前版本规则
- 支持多个大模型、多个公众号；模型和公众号一对一绑定。
- 同一选题可多选公众号，每个公众号生成不同版本，审核后统一写入草稿。
- 每个公众号可独立设置正文排版、草稿模板和正文替换字样。
- 模板中的视频、图片、跳转链接和公众号名片会原样保留。
- 正文硬性要求不少于 2000 字；不足会自动扩写，仍不足则禁止写入草稿。
- 改写时会显示当前步骤、百分比和累计用时。
- 正文按各公众号选定的模板和排版方案分别生成。
- 失败文章可从原文抓取、正文、标题、排版、配图或写入步骤原地恢复；只重试写入时
  会保留已确认版本。
- 写草稿具有持久化防重和结果对账：网络中断时会先查询近期草稿，不会盲目重复提交。

三、审核后二次修改
- 对正文不满意：在审核工作台选中段落，填写要求后执行“AI 二次改写”。
- 对图片不满意：可只重生一张正文配图、删除配图，或按新要求重生封面。
- 修改完成后仍停留在当前审核文章，旧确认自动失效，需要重新点击“确认此文章”。
- 所有修改前都会保存版本，可从历史版本恢复。
- AI 评审智能修改完成后会在当前审核页左右展示原稿与修改稿，确认差异后再审核文章。

四、飞书使用
- 在“设置 → 飞书”填写企业自建应用凭证并选择飞书智能体模型。
- 飞书可查询热点、创建多公众号批次、查看进度、选择标题/副标题、修改段落和图片、
  逐篇确认并写入草稿箱。
- 会修改内容、配置或产生模型费用的操作需要一次性确认码确认。

五、微信公众号固定 IP 云中转
- 让公众号管理员把云服务器固定出口 IP 加入公众号开发者 IP 白名单。
- 在“设置 → 系统设置 → 微信公众号云中转”启用中转。
- 填写 HTTPS 网关地址、管理员分配的中转用户名和中转密码。
- 选择一个公众号点击“测试并保存”；测试只读取草稿箱，不会创建或修改草稿。
- 测试成功后，token、正文图片、封面、素材、模板和草稿接口会自动走云中转。
- AI 模型、飞书长连接和文章抓取不会经过微信云中转。
- 每位客户应使用独立中转账号，不要多人共用密码。

六、文件说明
- data/app.db：用户添加的模型和公众号配置；API Key / AppSecret 已按 Windows 用户加密。
- config.yaml：选题、排版、广告和模板配置。
- data/templates/*.html：各公众号隔离保存的模板快照。
- data/*.json / keywords.txt：热点、同行及广告标题缓存。
- data/logs/package-self-test.json：安装包离线自检结果。

七、注意事项
- 安装包不会携带开发电脑上的密钥和历史数据库；首次安装需自行配置。
- 不要把 data/app.db 复制给其他 Windows 用户，DPAPI 密钥无法跨用户解密。
- 运行时不要重复双击多个程序。
- 微信密钥失效时，可直接在“设置 → 公众号”管理对应公众号并更新 AppSecret。
- 若 18765 或 18766 端口已被其他程序占用，请先关闭旧版公众号改写助手。
